# Legacy glyph dictionary

Schema v2 stores words. These mappings support reading schema v1 journals.

| Glyph | Action |
|---|---|
| E | edit |
| W | write |
| T | test |
| B | build |
| C | commit |
| Q | query |
| D | decision |
| F | fix |
| M | milestone |
| R* | rename |
| X | delete |

Results: `success`, `failure`, `wall`, `blocked`, `retry`, `unknown`.
