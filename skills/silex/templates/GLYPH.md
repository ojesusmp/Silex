# Glyph dictionary

Single characters compress what would otherwise be 5–15 words. Keep entries one line.

## Actions
| Glyph | Meaning |
|-------|---------|
| `E` | edit existing file |
| `W` | write new file |
| `T` | test run |
| `B` | build / compile |
| `C` | commit |
| `Q` | significant query / research |
| `D` | decision (picked X over Y) |
| `F` | fix applied (resolves a wall) |
| `M` | milestone |
| `R*` | renamed / moved |
| `X` | deleted |

## Results
| Glyph | Meaning |
|-------|---------|
| `✓` | success |
| `✗` | failure |
| `⚠` | wall hit (blocker discovered) |
| `⏳` | blocked (waiting on external) |
| `↻` | retry in progress |
| `?` | unknown / inconclusive |
